TrackMe.AI

Plan → Focus → Learn → Remember

TrackMe.AI is a productivity and learning management application designed to help students and developers plan their tasks, stay focused with Pomodoro sessions, track what they learn, and automatically schedule revisions using spaced repetition.

🚀 Features
📋 Task Management — Create and manage daily learning tasks.
⏱️ Pomodoro Focus Timer — Stay focused using structured study sessions.
📊 Automatic Time Tracking — Track the time spent on each task.
🧠 Learning Topic Capture — Record what you learned during a focus session.
🔄 Spaced Repetition — Automatically schedule revisions for learned topics.
📧 Email Reminders — Receive reminders for upcoming revisions.
🔔 Overdue Notifications — Get notified about unfinished tasks and revisions.
📈 Progress Dashboard — Monitor learning and productivity progress.
🧠 How It Works
Plan
  ↓
Focus
  ↓
Learn
  ↓
Remember
  ↓
Revise
  ↓
Repeat
1. Plan

Create your learning tasks for the day.

2. Focus

Start a Pomodoro session. Track the time you spend working on the task.

3. Learn

After the session, record the topic you studied.

4. Remember

TrackMe.AI schedules revision sessions using spaced repetition.

5. Revise

Receive reminders when it's time to revise the topic.

📅 Spaced Repetition

After learning a topic, TrackMe.AI schedules revisions based on:

Day 1
  ↓
Day 3
  ↓
Day 5
  ↓
Day 7
  ↓
Day 10
  ↓
Day 15

This helps users retain concepts instead of simply learning them once and forgetting them.

⚙️ Installation
1. Clone the repository
git clone <your-repository-url>
cd TrackMe.AI
2. Install dependencies
npm install

If frontend and backend are separate:

cd client
npm install


cd ../server
npm install
3. Configure environment variables

Create a .env file inside the backend:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
EMAIL_USER=your_email
EMAIL_PASSWORD=your_email_password

Never commit your .env file to GitHub.

4. Start the application

Frontend:

npm run dev

Backend:

npm run dev
🎯 Project Goal

The goal of TrackMe.AI is to solve a common problem among students and developers:

Learning consistently but forgetting what was learned.

Instead of being just another task manager, TrackMe.AI combines productivity + focused learning + automatic revision into one system.
