# TrackMe.AI

> Plan → Focus → Learn → Remember

TrackMe.AI is a productivity and learning management application that helps users plan their tasks, focus using Pomodoro sessions, track what they learn, and revise topics using spaced repetition.

---

## 🚧 Project Status

**Work in Progress**

---

## ✨ Features

- 📝 Create and manage daily tasks
- ⏱️ Pomodoro focus timer
- 📊 Track time spent on tasks
- 🧠 Capture learning topics
- 🔄 Automatic spaced-repetition scheduling
- 📧 Revision email reminders
- 🔔 Overdue task and revision notifications
- 📈 Productivity and learning progress dashboard
- 🔐 User authentication
